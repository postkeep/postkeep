# Brand assets

The postkeep repository images. Publisher: postkeep.

| File | Use |
|---|---|
| `readme-banner.png` | README header (1280×640) |
| `postkeep-app-icon-on-dark.svg`, `postkeep-app-icon-on-dark-512.png` | App icon, for example the GitHub repository avatar or an MCP client directory |

All three are byte-for-byte copies from the postkeep brand book at
commit `7e5f6dc8e7db0260b9e8eb4b809cd1351c12e873`: `readme-banner.png` of
`assets/social/repo-social-preview-1280x640.png`,
`postkeep-app-icon-on-dark.svg` of `assets/app-icon/postkeep/app-icon-1024.svg`
and `postkeep-app-icon-on-dark-512.png` of `assets/social/repo-avatar-512.png`.
The docs site keeps its own brand files in
[`site/public/`](../../../site/public/). The server's own favicons, touch icon
and web app manifest, in
[`crates/auth/assets/brand/`](../../../crates/auth/assets/brand/), still
carry the earlier brand.

Write the name in lowercase: postkeep. The license of the postkeep logo and
brand assets hasn't been decided yet. The code's MIT license doesn't cover
them.

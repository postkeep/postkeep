# Fastmail

Fastmail connects with an app password. Create one in
[Fastmail's app password settings](https://www.fastmail.help/hc/en-us/articles/360058752854-App-passwords),
then sign in with your Fastmail address and paste it. The sign-in page
shows the same steps.

Fastmail is offered by default ([mail providers](../configuration.md#mail-providers)).
